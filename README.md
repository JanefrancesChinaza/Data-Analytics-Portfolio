## 📂 Featured Project Summaries

### 1. FIFA World Cup Data Reconciliation & Analytics Dashboard
* **Problem:** Raw historical data across multiple tournament years contained missing records, schema inconsistencies, and unlinked relational tables.
* **Solution:** Cleaned and transformed data using Power Query, established a robust Star Schema data model, and authored custom DAX measures for complex dynamic KPIs.
* **Outcome:** Delivered a clean, multi-page Power BI dashboard providing actionable analysis on team performance, player trends, and match metrics over time.
* 🔗 **[Explore Full Project Repo & `.pbix` File](#)**

### 2. Titanic Survival Exploratory Data Analysis (EDA)
* **Problem:** Identify key passenger attributes that influenced survival probabilities to demonstrate demographic insight extraction.
* **Solution:** Cleaned missing values, performed univariate and bivariate exploratory analysis, and constructed clear visual breakdowns using charts and statistical summaries.
* **Outcome:** High-priority indicators (e.g., class distribution, age groups, and fare brackets) were mapped to highlight significant variance in survival outcomes.
* 🔗 **[Explore Full Project Repo & Code](#)**

### 3. Financial & Insurance Data Cleaning & Reconciliation
* **Problem:** Transaction logs required structured auditing to reconcile billing mismatches and duplicate records.
* **Solution:** Applied advanced Excel formulas (`XLOOKUP`, nested logic, conditional checks) and automated cleaning steps in Power Query.
* **Outcome:** Reduced reconciliation errors and established a repeatable reporting template for fast data audits.
* 🔗 **[Explore Full Project Repo & Spreadsheets](#)**
