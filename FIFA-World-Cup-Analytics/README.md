# FIFA World Cup Historical Analytics Dashboard

## 📌 Overview
Consolidated and reconciled 5 years of historical FIFA World Cup match data into a clean star schema model using Power BI and DAX.

## 🛠️ Tools Used
* Power BI (Power Query, Data Modeling, DAX)
* Microsoft Excel

## 📊 Key Highlights
* Consolidated disparate tables across multiple tournament years.
* Built dynamic interactive visuals for match trends and performance KPIs.
